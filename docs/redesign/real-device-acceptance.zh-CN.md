# 实机验收步骤（发版前由人来做）

自动化已经在真实 WKWebView 里验证了下载、文件选择、外链、窗口背景和页面布局（见验收表“阶段 7 记录”），但下面这些只有真人在真实电脑上才能确认。每一项做完在 [验收表](acceptance-checklist.zh-CN.md) 第 10 节勾选并写上日期和环境。

候选安装包用 `./packaging/macos/build-dmg.sh` 构建，输出在 `build/macos/CloakBrowser-Manager-<版本>-<提交>-<架构>.dmg`。

## 开始前

1. 在**现在在用的版本**里先做一次完整备份（数据 › 立即完整备份），并把备份文件另存到别的地方。新版本只给数据库加了一个版本号记录，不改现有数据，但备份是发版前的惯例。
2. 记下现在用的版本号（设置 › 关于与更新）。

## macOS 应用（X-01、X-03、X-05）

- [ ] 打开 DMG，把应用拖进“应用程序”覆盖旧版。双击打开，只出现**一个**窗口，环境列表和数据都在。
- [ ] 点 Dock 图标：窗口回到前面，没有出现第二个窗口。关闭窗口：应用还在 Dock 里；再点 Dock 图标，窗口回来。
- [ ] 菜单栏：打开面板、版本、检查更新、数据目录、日志目录、登录时启动、重新载入，每项点一下，都有响应。
- [ ] 打开一个环境的浏览器，再 Cmd+Q 退出应用：浏览器跟着关闭，没有留下后台进程（活动监视器里搜 CloakBrowser）。
- [ ] 重新打开后，到“设置 › 关于与更新”点“检查更新”，能给出结论（已是最新或有新版本）。
- [ ] 可选：`./uninstall-macos.sh` 默认只删程序文件、保留数据目录（加 `--purge-data` 才会一并删除，别在有用数据时加）。

## 深色模式（窗口外观）

- [ ] 在“设置 › 外观”选深色，退出应用再打开：窗口出现的第一帧就是深色，没有白闪。
- [ ] 在设置里切换浅色 / 深色 / 跟随系统：窗口标题栏和背景立刻跟着变。

## 下载、上传、外链（X-02，真人点一遍原生对话框）

- [ ] 数据 › 立即完整备份：弹出“存储为”对话框，选位置后文件完整，能用访达解压。
- [ ] 数据 › 从备份文件恢复、数据 › 导入配置：弹出系统“打开”对话框，选中文件后页面收到它。
- [ ] 环境编辑页的 Cookie 是粘贴文本、导出时走下载，没有文件选择，不需要单独测。
- [ ] 设置 › 关于与更新里发现新版本时点“手动下载安装包”：用默认浏览器打开，应用窗口不变。

## 新旧检测报告对比（X-06，会占用授权席位并访问外部检测站，请先关闭其他浏览器）

1. 用**旧版本**对同一批环境（建议 2–3 个，包含一个带代理的）跑“检测 › 一键检测报告”，在报告详情点“导出报告（zip）”，保存为 `old-<环境名>.zip`。
2. 换成新版本，对**同一批环境**再跑一遍，导出 `new-<环境名>.zip`。
3. 每个环境各运行一次：

   ```bash
   python scripts/compare_check_reports.py old-环境名.zip new-环境名.zip
   ```

   退出码 0 表示每一项结论都一致。“差异”里出现的项要看是变好还是变差；“需要留意”里的出口 IP 不同，说明两次不是同一条件，先让两次用同一个出口再比。

## 回退保险

- [ ] 设置 › 关于与更新 › 切换回旧版界面：窗口改用旧版界面；在旧版左下角点“试用新界面”能回来。重新打开应用，打开的是你最后选的那个界面。

## 一键更新与回滚（X-05）

只有在两个真实发布版本之间才能完整验证：先装旧版本，再在设置里点“立即更新”，确认更新前自动做了备份、应用自动重启后版本号变了；失败时 macOS 会自动换回上一版。发版时按这个顺序做一遍。

## Windows（X-04，没有在 Windows 上做过任何验证）

需要在 Windows 电脑上做：

- [ ] 运行 `packaging\windows\build-installer.ps1` 构建安装包，安装，托盘出现图标，面板在 Chrome 应用窗口里打开并显示新界面。
- [ ] 窗口拖窄到 900 像素：不出现错位，侧栏收成图标。
- [ ] 托盘菜单：打开面板、检查更新、打开日志目录、登录时启动、退出，每项都有响应；退出时浏览器一起关闭。
- [ ] 深色模式下 Chrome 应用窗口的标题栏和面板协调（外壳没有为 Windows 做主题联动，只是面板自身的深色）。
- [ ] 日志超过 10 MB 后会轮转成 manager.log.1（Windows 上的轮转没有实机试过，写文件时重命名/截断的行为可能和 macOS 不同）。
- [ ] 卸载后开机启动项被清理。
